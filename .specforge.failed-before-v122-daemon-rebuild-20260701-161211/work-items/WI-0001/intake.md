# WI-0001 Intake：基础数据与权限骨架

> 来源：飞检现场管理系统_业务逻辑定稿_v1.14_最终干净版_开发输入.md（第105.1节 阶段1）
> 创建时间：2026-07-01

## 1. Work Item 范围

WI-0001 对应 v1.14 MVP 阶段1「基础数据与权限骨架」，包含 7 个核心对象：

1. **User**（用户）：系统用户账号
2. **Role**（角色）：项目级角色定义
3. **Permission**（权限点）：基础/业务/流程三类权限
4. **Organization**（组织机构）：站场、阀室、第三方检查机构等主数据
5. **Project**（项目）：飞检项目主实体
6. **ProjectOrganization**（项目-组织关联）：项目关联的参建单位
7. **UserProjectRole**（用户-项目-角色关联）：用户在项目中的角色分配

## 2. 业务需求摘要（来自 v1.14）

### 2.1 用户规模
- 20–50 名用户，10–20 人同时在线（v1.14 第103节）

### 2.2 权限模型
- 项目级 RBAC，所有项目数据查询必须校验 project_id 权限范围
- 权限三分类：基础权限、业务权限、流程权限
- 角色：系统管理员、项目负责人、组长、检查员、报告编制人、报告审核人、查看者
- 一人多角色支持
- 组长、项目负责人为独立 role_code，可由同一用户兼任（v1.14 裁决C13）

### 2.3 组织机构
- Organization 是主数据（站场/阀室/第三方检查机构）
- User 可关联 Organization（User.organization_id）
- ProjectOrganization 表达项目参建单位关系
- 第三方检查机构通过 Organization 表达
- 安卓端不直接创建正式站场/阀室主数据（v1.14 裁决C14）

### 2.4 项目配置
- 项目默认配置模板（v1.14 第103.7节）
- 项目结束后默认只读状态
- 项目时区配置（project_timezone）

### 2.5 安全基线（v1.14 第103.3节）
- 认证：V1 仅账号密码登录
- 传输加密：生产环境 HTTPS
- 密码存储：安全哈希（BCrypt）
- 授权：项目级 RBAC
- 审计：关键操作留痕（OperationLog，含 log_hash 防篡改）
- 越权操作必须填写原因并留痕

### 2.6 初始化数据（v1.14 第103.7节）
- 默认系统管理员账号创建流程
- 默认角色：系统管理员、项目负责人、组长、检查员、报告编制人、报告审核人、查看者
- 默认权限点清单
- 默认审批模板：无审批、一级审批、两级审批
- 默认数据字典：机构类别、项目角色、专业、问题分类、严重等级、照片类型、报告类型
- 默认严重等级整改期限：一般7天、较大3天、重大立即整改
- 默认项目配置模板

## 3. 技术栈决策

### 3.1 整体技术栈
- 后端：Java 17 + Spring Boot 3.x
- 数据库：PostgreSQL 15
- 前端：Vue 3 + TypeScript + Element Plus
- 安卓：Kotlin + Room + WorkManager + DataStore

### 3.2 三项技术选型（v1.14 第106.2节 编码前冻结）

| 选型项 | 决策 | 理由 |
|---|---|---|
| 安卓离线数据库 | Room + WorkManager + DataStore | Android 官方首选，支持 schema migration，满足 App 升级迁移要求 |
| 照片/文件存储 | 服务器本地文件系统 | 简单直接，适合内部工具单机部署；目录分层 photos/{yyyy}/{MM}/{projectId}/ + SHA-256 哈希；文件目录与数据库一起备份 |
| 报告导出引擎 | Apache POI + poi-tl | 开源免费；poi-tl 模板引擎支持 {{占位符}} 语法，减少手工调参成本 |

## 4. 非功能基线（v1.14 第103节）

| 项目 | 基线 |
|---|---|
| 用户规模 | 20–50 用户，10–20 并发 |
| 列表查询 | P95 ≤ 800ms |
| 详情查询 | P95 ≤ 600ms |
| 传输加密 | HTTPS |
| 密码存储 | BCrypt 安全哈希 |
| 备份 | 每日全量，RPO ≤ 24h，RTO ≤ 24h |
| 审计 | OperationLog 不可编辑删除，含 log_hash |
