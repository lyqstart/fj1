# WI-0003 变更分类

**变更类型**: ops_task / task_change_path
**变更性质**: 生产服务器首次部署（破坏性运维 + 数据库版本变更）
**风险等级**: 高

## 变更范围
- **基础设施**: PG13 → PG16（不可逆，旧数据销毁）
- **运行时**: 新增 JRE17、systemd 服务、Nginx 站点
- **应用**: 后端 fat jar + 前端 dist 首次部署
- **旧系统**: PM2 NestJS 系统停用 + /opt/fj 备份清理
- **命名变更**: fj → fj1（路径、服务名、DB 用户/库名）

## 变更分类
- 破坏性: 是（PG13 销毁、旧系统下线）
- 可回滚: 部分（PG13 数据可备份恢复；旧系统可从备份恢复；Flyway 失败可回滚 jar）
